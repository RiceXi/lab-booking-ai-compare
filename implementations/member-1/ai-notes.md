## 4. AI 生成错误与修复

### 4.1 SQLite 连接未关闭

- 现象：首轮测试出现大量 `ResourceWarning`，Windows 临时数据库被占用，测试清理失败。
- 原因：误认为 `with sqlite3.Connection` 会自动关闭连接；该上下文只负责事务提交/回滚。
- 修复：增加 `_connection()` 上下文管理器，在 `finally` 中显式 `connection.close()`。

### 4.2 自定义连接上下文未提交

- 现象：设备插入后查询返回 404，AC 测试全部失败。
- 原因：第一次修复只关闭连接，没有在成功路径调用 `commit()`，关闭连接时事务被回滚。
- 修复：正常退出时提交，异常时回滚，最后始终关闭连接。

### 4.3 前端空状态选择器错误

- 现象：浏览器提示 `Cannot set properties of null (setting 'hidden')`。
- 原因：页面中存在多个 `.table-panel`，选择器命中了设备空状态，而不是预约表格。
- 修复：为预约表格增加唯一 ID `reservation-table-wrap`，直接按 ID 控制空状态。

### 4.4 静态资源缓存掩盖修复

- 现象：修改 JavaScript 后浏览器仍执行旧脚本。
- 原因：静态资源缓存时间较短，但开发期间仍可能复用旧文件。
- 修复：给 CSS/JS 引用增加版本参数，确保复验使用最新资源。

### 4.5 测试期望与统计口径不一致

- 现象：AC11 首轮失败。
- 原因：测试把“已取消”记录计入了按设备统计的未取消预约次数，并误算某设备的历史数量。
- 修复：按页面口径把已取消记录排除在 `reservation_count` 之外，同时保留独立的已取消数量断言。
