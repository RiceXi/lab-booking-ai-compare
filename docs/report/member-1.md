## 5. AI 错误、幻觉与人工修改

### 5.1 SQLite 连接生命周期错误

AI 最初使用 `with self._connect() as connection`，误以为退出上下文会关闭连接。实际上 SQLite 连接上下文只处理提交和回滚。

现象：

- Windows 测试结束后无法删除临时数据库。
- 出现大量 `ResourceWarning: unclosed database`。

修复：

- 增加 `_connection()` 上下文管理器。
- 正常路径执行 `commit()`，异常执行 `rollback()`。
- 在 `finally` 中始终 `close()`。

### 5.2 事务未提交

第一次增加连接关闭逻辑后没有在成功路径提交，插入数据关闭连接时被回滚，后续查询返回 404。

修复：

- 自定义上下文正常退出时调用 `connection.commit()`。
- 异常路径调用 `connection.rollback()`。

### 5.3 前端选择器错误

AI 最初使用 `$(".table-wrap", $(".table-panel"))` 定位预约表。由于设备空状态也使用了 `.table-panel`，定位到了错误节点并产生空引用错误。

修复：

- 给预约表格外层增加唯一 ID `reservation-table-wrap`。
- 使用 `$("#reservation-table-wrap")` 控制空状态。

### 5.4 静态缓存问题

浏览器复验时仍执行旧 JavaScript。修复方式是在 CSS/JS 地址中加入版本参数，使浏览器重新加载更新后的资源。

### 5.5 测试期望错误

AC11 首轮测试把已取消记录计入“按设备统计的未取消预约次数”，并将一台设备的历史数量写成 2。根据页面口径修正为排除已取消记录后，该设备数量为 1。

### 5.6 不存在的 API

本轮没有调用不存在的第三方 API。实现只使用 Python 标准库和浏览器原生 API；前端图标使用本地 Lucide 图标子集，不依赖在线图标服务。

- 人类决定保留公共契约不变，并选择零第三方依赖路线。

## 6. 代码结构说明

```text
implementations/member-1/
├── booking.py                 领域校验、冲突检测、状态机、SQLite
├── server.py                  HTTP 服务、JSON 路由、静态文件
├── static/
│   ├── index.html             工作概览、设备管理、预约管理
│   ├── styles.css             桌面与移动端样式
│   ├── app.js                 表单、筛选、状态动作、统计图表
│   └── icons.js               本地 Lucide 图标子集
├── tests/
│   ├── test_acceptance.py     AC1-AC12
│   ├── test_rules.py          规则边界和并发测试
│   └── test_api.py            HTTP 集成测试
├── ai-notes.md                AI 过程原始记录
└── README.md                  运行、数据位置和测试说明
```

关键设计：

- 所有业务错误使用带 HTTP 状态码的 `AppError` 返回。
- 预约创建使用 `BEGIN IMMEDIATE`，在同一个写事务中完成设备读取、冲突查询和插入。
- 冲突条件严格使用 `new.start < old.end AND old.start < new.end`。
- 时间采用固定 `HH:mm` 字符串，配合 30 分钟粒度校验和半开区间比较。
- 状态流转由白名单控制，非法流转返回 409。
- 设备编号、名称、位置、预约人和备注长度由领域服务统一限制。
